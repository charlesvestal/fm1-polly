# Polly course

Short lessons, each with a video and a picture for every step. Take them in order. For every detail, see the
[manual](../../MANUAL.md).

| Lesson | What you do |
| --- | --- |
| [Quick start](../../QUICKSTART.md) | Write a verse and a chorus, and play them as a song. |
| [101 Playing live](101-playing-live.md) | Pick a style, play chords, switch grooves, end with an Ending. |
| [102 Your own progressions](102-your-own-progressions.md) | Record chords, fix one, set the length, name it. |
| [103 Your song](103-your-song.md) | Put progressions in order, choose grooves and repeats, play the song. |
| [104 Changing styles](104-changing-styles.md) | Hear your song in another style. |
| [105 Recording a melody](105-recording-a-melody.md) | Record a melody across the whole song. |
| [106 Your own grooves](106-your-own-grooves.md) | Record an instrument into a groove and keep it. |
| [107 Fixing notes](107-fixing-notes.md) | Change, add and delete single notes. |
| [108 Making it sound yours](108-making-it-sound-yours.md) | Sounds, the mixer and the effects. |
| [109 Keeping your work](109-keeping-your-work.md) | Save, the four songs, undo, memory and backups. |
| [110 With other gear](110-with-other-gear.md) | MIDI keyboards, MIDI out, clock and the screen mirror. |
