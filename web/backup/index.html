Back up Polly

Save Polly's songs to a file on this computer, and load them back later. Connect the FM-1 with a USB cable. This page works in Chrome or Edge, and there is nothing to install.

Plug the FM-1 running Polly into this computer with a USB cable.

Back up

This saves everything to a .plb file. That includes the four songs and their progressions, your grooves and melodies, and the settings. Polly can keep playing. If you have changes that aren't saved yet, stop Polly first so they go in the file too.

Restore

This puts a backup back on Polly, and it replaces everything there. Stop Polly first. Polly checks the whole file before anything changes. Then its screen asks RESTORE FROM USB? Press SEL on the FM-1 to restore, or HOME to keep what you have.

  • A backup doesn't hold the QY70 styles or the button calibration. Install the QY70 styles again from your ROM.
  • A cut cable or a damaged file changes nothing. Even a power cut during the write leaves either the old songs or the new ones, never a mix.
  • The browser asks once for permission to use MIDI with SysEx. Allow it, and close other apps that use the FM-1's MIDI first.
  • You can also back up from a terminal. Run python3 tools/polly_backup.py in Polly's repository. It does the same, and makes the same files.
